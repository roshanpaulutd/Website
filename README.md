# Portfolio Website

A responsive neo-brutalist portfolio website built with plain HTML, CSS, and JavaScript.

## Preview

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Project files

- `index.html` contains the page sections, navigation, project content, and contact links.
- `styles.css` controls the neo-brutalist layout, colors, responsive breakpoints, borders, shadows, and pixel-art placement.
- `script.js` controls the mobile navigation menu.
- `assets/` contains the lightweight local pixel-art SVG decorations.

Replace the placeholder name, links, project details, certifications, and experience entries in `index.html` with your own content.
